## Genuine remaining blocker

The original POD archives contain `particle\\podSpray.emt` (1027 bytes,
SHA25661ed9636b3b0db17fe60ed9c2a07d45d962436f4e217c9c4f1c58148c912bf17).
The previous assertion that the selected GC track archive lacks that member was
true but did not establish global resource absence. Two required spray objects
are created for a present334; a missing load is not a source-null spray route.

Their19CED0 child update needs the actual shared race ParticleManager70
(active128, capacity130, pointer table138, authored registry13C/140), common
15A7A0 emitter state and ordered application308030 RNG. Source19D538..54C and
19D830..844 use lazy shared3D6B30 and101A50→308020 clock-derived reseeding. This
manager/RNG ownership is also consumed by world fog and other race effects.
A private spray RNG, fresh private5000-particle pool, zero capacity, missing
particle writes, or stopped-owner substitution would not close that lifecycle.
The input EMT is retained but has not been newly extracted or decoded here.

Until that native shared lifecycle is implemented and connected, do not bind
water into live gameplay merely to get through216B78. This source packet is
concrete progress, not an assertion of working GC recovery.
