## Source order and numerical scope

The height query accumulates selected signed wake samples, optional raw noise samples and authored signature channels in original order. It preserves signed noise remainders, unsigned signature remainders, depth comparison and the optional effect-owner result. Missing state is an error, never an absent provider or zero texture.

Time proposals use the actual virtual-update delta and application pause field. They retain the separate render-published signature origins. They do not sample a host clock or claim that the original child-update continuation has completed. Arithmetic is bounded to normal finite values and signed zero with separate binary32 rounding; exceptional domains reject explicitly.

The signature loader requests a texture format, but the original PST loader replaces that format with indexed kind 1. With the original scoped texture-load flags, the last/largest level is retained unswizzled. Physics therefore reads its actual one-byte indices. Palette-expanded RGBA is not the physics plane. The existing decoder validates the member; this adapter retains the original index plane.

The WTT reader retains pool count, authored layout, channels and load masks. This slice does not construct pools. Cold signature admission is bounded to channels 0 through 3, positive square indexed frames and positive authored extents. Origins start at the original constructor's zero values and remain marked unpublished. A successful cold projection is not runtime-query admission.
