# 49O: Authored Pod01 geometry and secondary-body initialization

49O replaces the persistent two-body diagnostic's synthetic secondary mass, inertia, joint anchors, rest length, target offset and joint tuning with source-derived Pod01 values. The main tuning continues to come from the real PHY through49N. The same previously supplied initial poses and external effects are retained.

This is a selected numeric initialization path with explicit fresh-model assumptions. Complete vehicle construction, physical-scene pose/history, centers, world contacts, reset effects and the full game scheduler remain separate dependencies. No playable-race, presentation-FPS or original-Xbox performance claim is made.

## Actual inputs and sequence

The unchanged original POD01.RES (349,110 bytes; SHA25608b4d7655cb796da8a29d9b9a5318c0364561c659794ac9de6c9dfed7416eca3) is already preserved in the49N baseline. The retained bounded RES decoder extracts15 exact MCF/PSG/VUT/MOT members for this evidence. No additional transfer, installation, PC operation or RAM input is needed.

Production accepts bounded zero-copy PSG hierarchy and MOT views, plus typed model-node bindings. Only the PSG hierarchy prefix is parsed by the new reader; render streams/materials are not validated or used by this calculation. The original member bytes remain caller-owned. The actual selection is tied to the PHY `[Pod Setup] Prefix="01"`, Chariot model, MCF `01_Forward`/`01_Back` records and their `.MOT` extension resolution. General MCF resource management is not reimplemented.

1. Capture pre-animation Chariot `nullcg` local XYZ. Capture right-engine `nullcg` worldZ using the original matrix-product order, before its original translation clear.
2. Enumerate original model motion rows by sibling group then child subtrees. Apply VUT renames and flags without reordering scene references. Actual Pod01's rows coincide with PSG order, but the native map supports source-proven non-identity order too.
3. Original213830 calls155E70 with Forward, Back, frame fraction0.5, blend0 and mirror0. Both motions sample at the FIRST motion's duration×0.5. Blend0 still executes interpolation and quaternion arithmetic; direct key copying or an assumed even blend would be wrong.
4. Write rotations, then positions, in source track order. Preserve all unaffected local matrix lanes. ByteAxis, Bezier, quaternion hemisphere, table interpolation and matrix normalization follow original arithmetic.
5. Recompute all18 Chariot node world matrices and original26F4B0 box aggregation. Every source node is eligible, including dummy/zero bounds. Model-root own bounds are disabled on the admitted fresh path. Stored sphere radius is not used.
6. Apply original secondary mass/inertia setters and complete inverse matrix; derive target/rest and anchors; initialize49L's original stiffness/damping and setup caches after the new inertia is installed.

## Precision and context

All native math requires FE_TONEAREST, separate binary32 operations, no fast-math or FMA. Trig table values are generated by the original software sine/cosine/acos and conversion instructions under the existing admitted scalar rounding model; production uses2,561 immutable words. Acos lookup slot2048 is the original cold-start-zero BSS padding word. This is an explicit initialized-table context, not a claim that every later game execution preserves it or that hardware FCR behavior has been completely emulated.

Fresh model roots are unparented identity graphics roots, established by the constructor/basis/orientation source path. The bound routine recomputes supplied local transforms and does not emulate arbitrary stale-world-cache states. Scene registration/material setup and IK-constructor reads were audited for this path; optional unrelated effects are not executed. Physical body initial poses, centers, derivatives/history, additional loads and contact/query effects remain supplied contracts.

Independent review found a missing positive-zero addition before the root transpose on reflected signed-zero inputs. The final implementation includes the original VADD operations. A retained minimal failure and512 independent adversarial cases verify the correction. Authentic Pod01 results did not change.
