Math
For source homogeneous position P, sequential planes are Z+W, W-Z, Y+W,
W-Y, X+W, W-X. Distances >=0 are inside. For directed edge A -> B and
distance values da/db, crossing positions and attributes use:
 A + (B-A)*da/(da-db) when A is inside;
 B + (B-A)*db/(da-db) when A is outside.
These retain the original two endpoint forms (367330 / 367380), without
attempting VU rounding, instruction timing, or guest state reproduction.
The source edge loop starts last -> first and writes A if inside, followed by
an intersection if crossing. The native code retains that polygon rotation.

Raw RGBA is homogeneous-edge interpolated through the FIRST near plane.
Then multiply RGBA by source W (3669C0), clip the other five planes, divide
by final W (367160), and truncate nonnegative channels to byte values
(367180). Thus a negative-W input does not cause the same generated color
as globally screen-linear GL clipping.
UV is homogeneous-edge interpolated, then uses native perspective raster
interpolation. The original366678 multiplication restores raw STQ before
clipping;367168 divides XYZ afterwards. Fog is the independent fourth lane,
not multiplied by W in either operation. It is homogeneous-edge interpolated
for all six planes, then packed FTOI4 (367188); final byte F is screen-linear.
The native geometry stage emits floor(F) * nativeClipW; the existing fragment
stage reconstructs screen-linear F by multiplying gl_FragCoord.w.
A triangle with no source-plane exclusion passes through without introducing
additional vertex byte rounding.

Limitations
Native IEEE shader arithmetic, UV filtering, depth clipping, rasterization,
MSAA and screen-coordinate subpixel rules are still native policy. There is
no hardware bit-parity claim. Original model-space matrix multiplication
rounding is not reproduced by the already-lowered world-space geometry.
The mathematical polygon capacity assumes finite, convex source operands;
there is no GPU per-primitive arithmetic fault readback in this GL4.0 slice.
Host asset and camera admission, GL resource-limit errors and compile/link
fault reporting remain active. Adding an invalid-operand feedback channel
would be a distinct API/resource change, not silently inferred here.

Review revisions: topology admission and boundary capacity
Before GPU allocation, every admitted draw-plan triangle must have the exact
chronological set n,n+1,n+2, allowing only A/B reversal, within its placement
vertex range and signed GL vertex-ID range. Failure is an explicit assets
error. This verifies the imported invariant rather than guessing global
triangle parity or relying on gl_PrimitiveID (which resets for individual
blended draws). Actual strip restarts and group boundaries need no new GPU
metadata because their chronological vertex records remain consecutive.

Exact zero-distance endpoints retain the source duplicate intersections.
Removing duplicates would change later polygon rotations and can move the
fan anchor, so that tempting optimization is not source-equivalent. For a
convex polygon, an intersecting plane has at most two crossing edges and
removes at least one vertex: n_next <= n-1+2 = n+1, including intersections
coincident with retained endpoints. An all-inside plane emits n vertices and
still performs the source cyclic rotation. Starting at3, six planes need at
most9 slots. Exact boundary duplicates do not break this capacity proof.
Empty or less-than-three-vertex polygons have no filled area and emit none.
This is the geometric capacity proof; the existing limitation concerning
nonfinite or exceptional GPU arithmetic is not claimed resolved by it.

Per-plane control flow review
The source runs each complete edge loop in order. The branches after the six
loops at366950,366B10,366C80,366DE8,366F50,3670B8 test empty output and leave
the clipper. The intervening IBGTZ branches choose the alternating polygon
buffer (102 versus142); they do not bypass a plane. Per-edge clip masks select
inside/outside/crossing cases within a loop. Thus an all-inside plane still
copies last,first,... and rotates the polygon. The native six rotations are
intentional, including exact coincident endpoint records.
