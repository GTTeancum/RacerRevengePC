# Invariant-alpha map-2 batching remains held

Source review only. No implementation, execution checks or measured improvement.

## Existing behavior

vehicle_shader_gl50cz.cpp::vehicleGlFragmentSource50CZ computes sourceByte as
floor(clamp(texture(image,uv)*255*clamp(sourceColor*255,0,255)/128,0,255)).
sourceColor is noperspective. Base and map-2 select different textures and UVs.
Map-2 replaces destination alpha; its RGB recurrence is saturated
floor(sourceRGB*destinationAlpha/128)+destinationRGB. Fog changes RGB only;
optional map-2 alpha testing discards source alpha below one.

The opaque source-diffuse policy in validateMaterialPolicy does not certify
texture alpha. original_racer_material50km.h projects all four RGBA lanes;
vehicle_draw50cm.cpp copies all four generated bytes into live vertices.
projectSmallDirectionalRegistry clears directional fourth lanes but retains the
actual zone-ambient fourth lane, not a universal 128. GPU texture metadata stores
identity/name without a constant-alpha certificate.

## Missing proof

No qualifying actual span has been established. Matching each triangle's map-2
alpha to its own base alpha is insufficient: the complete group base pass runs
before map-2, so another overlapping equal-depth triangle can be the final base
alpha writer. Admission would need one common resulting byte K for all relevant
base/map-2 fragments and proof that each depth-passing destination sample has K.

A possible conservative candidate is authenticated all-alpha-255 textures plus
all relevant current vertex alpha bytes equal to255, saturating to255 in the
mathematical shader formula. Actual eligible assets, interpolation, sampling,
GPU arithmetic, coverage and per-sample base provenance remain unproven.

Even fixed K establishes only mathematical commutativity of nonnegative
saturated RGB additions. The current single payload image cannot retain multiple
overlapping fragments, and replacements from one snapshot would lose updates.
An accumulation design needs a separate correctness proof; direct stronger
batching or fixed-function blend substitution is not justified.
