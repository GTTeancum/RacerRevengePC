## Duplicate and lifetime guards

A session rejects duplicate scene IDs, physical/graph occurrences, model/query
component keys, and canonical query identities. Used slots are tombstones after
native revocation and are never reused within that domain/session. Resolution
checks current component references, keys, generations, canonical shape identity,
and model graph identity against the publication snapshot.

The query Storage destructor revokes by its private slot/generation token only.
It does not dereference model/query/physical borrows: current native component
storage may already have been destroyed by declaration order. Local domain
storage is still alive during that destructor body. Native revocation is safety
housekeeping, NOT source11B4A0 retirement or permission to destroy live gameplay.
The physical provenance borrow is compare-only and is never used as an implicit
live-domain pointer after revocation. Response requires a separately retained
live domain argument and an unrevoked entry.

External shared domains MUST outlive every borrowing query owner. Their explicit
close rejects any live publication. Once closed, they cannot be reopened or
repurposed. Existing source query/effect/reference retirement gates remain; this
patch adds no published-retirement shortcut. Unpublished world cancellation
contains no resolvable entry and retains its existing terminal guards.
