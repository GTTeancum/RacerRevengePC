## Source-to-surface representation

Every placement retains original SCB matrix and use-lighting value, actual payload and canonical material handles. The flattened cold view explicitly selects LOD0; every source LOD remains retained in the immutable payload, and this does not claim original runtime LOD selection.

For local single-root models, SCB replaces the saved root transform. Source world-space models bypass that root. `Scene48D::position_local` already contains quantization scale and origin; neither is applied twice. Positions are transformed using the existing semantic binary64 representation, then bounded to finite binary32 host vertices. Local source normals, UVs, source surface ordinals, material slot and canonical row are retained. Normal/raster lowering is still a future draw-owner duty.

The source-color presence bit is explicit. Colorless source data never gains synthetic white/prelit colors. Retained source use-lighting is data, not an inferred shader policy. Fixed native geometry ceilings (1,000,000 vertices and 3,000,000 indices) reject overflow; no source execution has measured this new owner's actual output or confirmed construction succeeds.

The four fire mappings are derived privately while walking the owned SCB records: zone 1, ordinals 366–369, exact geometry `firep0t01.psg`–`04.psg`, unique matching `FireP0t01.slt`–`04.slt`, and their actual generated surface ranges. No caller-supplied replacement indices enter this mapping. These are cold source subset identities, not completed-draw evidence.

## Failure and lifetime

One attempt per stage, aggregate terminal failure on any rejection. A stable placement owner is installed before store-before-retain acquisition so a partial canonical reference prefix remains owned. Corpus additions and acquired prefixes are not rolled back as though they never happened. A later explicit close preflights release and releases each placement's existing source slots through `release26E4C0`; payload/domain/source retention outlives all references. Exceptions are contained with retained effects available for close. Destruction terminates on an unreleasable reference contract rather than silently discarding it.

Cold views are valid only while this aggregate owner remains staged and open. No GPU publication is possible through this API. A later renderer join must add the same private lifetime/retirement guarantees before lending these views to asynchronous GPU users.
