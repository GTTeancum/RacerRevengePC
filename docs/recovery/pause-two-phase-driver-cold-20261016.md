# Same-Application Pause cold and FINAL join

`original_pause_cold50LA::Owner` holds actual authenticated source data, native
prewarm references, the later counted Pause borrow and native draw owner. It is
single-attempt and retains partial ownership on failures. It is declared before
later renderer/resource borrowers; explicit `retireDrawing` rejects any surviving
renderer strong borrow. The race independently retains its actual Pause100.

## Root call sites

- Adjacent to existing PositionStats prewarm, before `raSession->construct` calls
  `prepareStaticWorld`, call `Application::prewarmPauseCold50LA(owner)`. This mounts
  the authenticated OVERLAYS archive, appends its five genuine authored materials
  and three PST sources, retains the exact36 Pause reference requests (including
  authentic missing-PSM backdrop provenance), and loads the real denmark16 font.
  There is no counted Entity or collector rebuild. Actual directory changes are
  scoped and restored on every return/exception.
- Pass the actual consumed race and this same owner as the final optional two
  arguments to `ra_native_session50LA::Join::construct`. They must be both present
  or absent. The default legacy call is unchanged. After actual racer construction
  and its existing combined world image population/FINAL collector, the join calls
  `loadConsumedPauseCold50LA(race,owner)` using the already-positive prewarmed rows. It uses the real race100 publication factory, then
  existing base backdrop/polygon/text/derived loaders and actual detached disable.
  Their genuine whole-table population calls must leave the captured FINAL seal
  and provider revision current; this is explicitly checked. Loading earlier
  would incorrectly populate crowd.atm before its actual six-frame lease exists.
- After that same existing FINAL population, call
  `Application::finishPauseDrawCold50LA(owner)`. It initializes the existing
  canonical FINAL/pixel/policy/draw adapter without population or resealing.
  Bind `owner.drawing()` through renderer.bindOriginalPauseDerived, and bind the
  observation to `owner.storage()` plus the actual CameraSession/decoded source.

The actual renderer retains the native draw owner through GPU retirement. For a
paused presentation, the root advances the real Application250 clock and uses
actual observer geometry/layout and viewport admission, then the renderer's
retained-race Pause submission. It must not submit a frozen full gameplay frame
again or add the host menu panel. This helper itself performs no input, clock,
geometry, GPU submission or gameplay work.

## Cleanup and limits

Close/retire the renderer's actual Pause GPU owner first, then `retireDrawing` to
release its FINAL pin/material admission. Disable/detach the actual Pause/race
forest and invoke native consumed-race cleanup; any other strong storage borrow
may survive only as already-closed backing. Helper close releases its prewarm
references once and its own storage borrow. Actual populated source/font entries
remain in their same Application registry until that owner's checked cleanup.

Partial source/reference/font/load/native-adapter failure retains all acquired
objects. No missing material/pixel is fabricated, and unsupported native GS
policies continue to reject through the existing adapter. Only the explicit
native late-load join is provided; full original race slot30/destructor parity,
result/restart branches and actual scheduler activation are not claimed.
Source review only; no builds, tests, syntax checks or decoder execution.
