## Pixel and mip representations

49 immutable bank identities:40 ordinary bases,3TGA bases,6crowd frames. Bank IDs are private local ordinals, never canonical resource tokens. Budgets are checked sums of the actual owned images. Each family retains its canonical row/token/context and source-to-image range. All authored or constructed mip records remain independently owned; the base bank makes no GPU mip policy.

Indexed: reuse `decodeTexture48E`; raw palette alpha is preserved. Match canonical levels to exact descending source ordinals, original palette, offsets and linear indices. Never decode transferred packed100 storage as source pixels.

TGA: read actual final canonical1555/8888 level storage, preserving exact dimensions, generated provenance, known F8bit2, source orientation/conversion and original mip arithmetic. No duplicate TGA decoder or generated-output pin. MetalGrate/TwiDesigns02 are admitted only with their proven actual TA0=TA1=255/AEM0, so even uncovered packed words sample alpha255. The existing resource `sourceKind/pstExtent` accessors only expose indexed resources; this consumer correctly uses `sourceFormat==pstIpum`, exact lease provenance and canonical level fields instead of assuming those accessors support kind2. No shared API was broadened.

The crowd family's `animatedCurrentMapPending` is true and `contextAfter249610Available` is false. ## Failure, serial entry and cleanup

Before corpus mutation, scan actual texture rows and reject a live canonical crowd resource. This stage cannot replace a warm adopted set. An existing weak set binding that is not observable as a row is still rejected by the existing private bind API, potentially after harmless source append; that prefix is retained. Repeated RA session entry is not admitted and no alternate Application/resolver is created to bypass the limitation.

Source append/population/image validation failures are terminal for this aggregate stage. Earlier material/resource/cache effects remain in their real owners. Cleanup releases real placement material references first, allowing actual child retirement, then drops world-owned image views and set/stage references. Partial resource owners may continue retaining the set through the actual canonical table. No native GPU borrower is admitted, and this patch does not change publication or GPU retirement policy.
