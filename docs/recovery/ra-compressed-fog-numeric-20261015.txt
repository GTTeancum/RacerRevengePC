Native equation, in distinct binary32 operations:
  delta=rawPosition-localCameraRaw
  distance=native_sqrt((dx*dx+dy*dy)+dz*dz)
  biased=(524288-endProduct)+(distance*scaledSlope)
  clamped=max(524288,min(524543,biased))
  F=(floatBits(clamped)>>4)&255

is independent. No CPU/GPU interpolation or fragment operation is provided.

NATIVE CANDIDATE CONTRACT
prepareCompressed accepts pure operand snapshots, validates finite affine
matrix/positive scale/round-to-nearest, preserves lane order and separate
operations, and publishes output only on success. radialByte validates signed
24-bit source integers, finite arithmetic, computes the native sqrt candidate
and packs a byte. This is source-backed native math with possible visual
differences, NOT EFU/PS2 bit parity. It cannot mint any owner lease or renderer
permission. No tests or shader checks have been run. No shared native rejection
was removed; no guessed compute-fog bit or all-F255 fallback was installed.
