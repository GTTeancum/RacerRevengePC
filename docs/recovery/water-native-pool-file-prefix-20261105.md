The supported endpoints are deliberately separate:

- A source-table comparison or native service refusal retains its reached inner boundary and partial effects. It is not a source missing-file return.

No resource allocation, construction, resource reference, row association, whole+1B4 store, loader return, Water pointer-array publication, transform or rendering/gameplay readiness is established.
