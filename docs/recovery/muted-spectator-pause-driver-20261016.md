# Muted ALL8 spectator Pause driver

The consumed RA route with explicit RR_AUDIO=0 now enables the same counted
race/Pause ownership and native rendering joins. Direct startup without a
consumed Course launch and audible-output sessions retain their existing route.
This is a native spectator-menu input policy, not original human-input127870
admission. Every racer remains on its original AI and human count stays zero.

Real Escape/SDL Start edges open the original ordinary Pause lifecycle. Up/Down
use the original navigation callback; Enter/keypad Enter/SDL A invokes row0
Continue. Other rows remain explicitly unavailable. Focus loss, interrupted
polls and changed devices require neutral rearm. Opening also requires an actual
completed gameplay underlay matching the retained camera's nonzero publication.

While open, the driver does not step physics, AI, camera, world materials or
flames. Original Pause clock/geometry preparation runs once per new presentation,
then authentic native geometry is rasterized over the unchanged completed race
image. Resizing holds that image until the old extent returns or Continue admits
normal resized gameplay. Capturing a retained image does not tick geometry.
Disabled Pause participates in clock preparation once per genuine gameplay
presentation. Native focus/interruption resumption samples the existing original
clock-reset operation before a new menu edge.

Logical ALL8 audio stays real even with no audible device. Native menu service
uses elapsed host time in positive chunks of at most16ms, with a maximum64ms
catch-up budget; excessive wall time is discarded. This does not advance a world
step, source announcer scheduling, music envelopes, or source250. Existing group
state remains authoritative. Source command25's distinct Auxiliary/music/announcer
setting is not fully recovered, so audible Pause feedback parity is not claimed
and audible-output activation remains gated.

Any reached lifecycle, rendering or audio failure enters terminal native cleanup;
it is never converted into gameplay resume based on the visible open-state bit.
Explicit shutdown closes the real menu regardless of selected row before camera
and audio retirement. Existing checked GPU, Bank, world, counted group, FIFO,
Pause resource and display cleanup remain in their reviewed ownership order.

This change awaits central build/smoke validation. A basic four-screen gameplay
smoke alone does not certify physical controller behavior or all Pause rows.
