Source-only, not yet built or run. Central Windows preparation is pending.

The previous SA bridge intentionally admits only SA, so it cannot create an MA
intake by relabeling paths. Added a separate MA extractor and bridge using the
same existing native RES reader and the same bounded, exclusive-output flow.
No game process or guest instruction is executed by this extraction operation.
