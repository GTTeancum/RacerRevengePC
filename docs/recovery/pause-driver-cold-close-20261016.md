# Original Pause driver cold join and explicit native shutdown

The driver compiles the actual consumed RA prefix, Pause canonical prewarm,
typed Session late resource load, native FINAL draw preparation, same-camera and
same-decoded-source observation, GPU binding, and real race/Pause parent attach.
`sourceConsumedPauseActivation` remains false pending root's input/clock and
presentation integration. No direct startup manufactures a consumed launch.
Enabled audio uses the same actual race feedback emitter's optional Pause keys;
explicit muted policy still uses its existing muted owner.

## Reached shutdown order

1. If actual parent attachment succeeded, run the original menu shutdown leaf
   before its camera, feedback, and mixer owners retire. Genuine callback
   rejection preserves the owners; it is not converted into successful cleanup.
2. Retire PositionStats primitive/display leases, real camera/fades and Session
   racer resources, then the existing frontend/audio/GPU resources. The renderer
   must actually release its strong Pause draw owner before `retireDrawing`.
3. Close every existing GPU texture and native model owner. The terminal Bank
   operation preflights no active visit/read/FIFO pins and the actual RA bridge's
   camera/follow/roster/grid retirement obligations. It destroys every snapshot
   byte allocation and span registration before releasing the real RA pin.
   Count/byte/step reporting scalars survive; new reads, visits, steps, spans,
   registration, and sealing cannot reactivate a retired Bank.
4. Drop the driver source/runtime borrows, close the actual consumed race graph,
   world, seven groups and empty FIFO using their existing native ownership
   methods; then release the helper's canonical prewarm references.
5. Admit display closure only after all actual dependents retired, then close the
   still-current host. No original full destructor parity is claimed.

The post-close navigation-anchor and both membership-zone reports are captured
before their actual world source and track Storage retire. Contact reports are scalar counters. Retired Session/model/audio
owners retain their existing idempotent destructors; observers only retain weak
camera/source controls and make no post-close callbacks. Frame and closure
lambdas are no longer invoked after shutdown. Partial failures return before host
closure, preserving same-owner retries; a failed original callback remains a
separate explicit failure and is not replayed as synthetic success.

This patch depends on the reviewed Pause callback/scheduler export for
`closeNativeSpectatorMenuForShutdown`. The source startup prefix predates the
existing runtime try block; its previously installed counted owner remains the
checked exception fallback. Runtime activation remains gated while root reviews
that early failure boundary together with complete scheduler integration.
