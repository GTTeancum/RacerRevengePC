Delivered scope

  actual RA world, lighting Owner and camera OwnershipBridge.

  Session, checking published stage, generation, serial and live idle Bank.
  No caller camera matrix, ready flag, racer DrawLease or fake membership.

  color fold. The private static entry accepts only the actual adapter.

  revalidates camera/world/light lifetimes. Copied values are not draw permits.

Explicit native policy
Static selection uses the authored one-based placement zone and original SCB
Position retained in authoredMatrix[12..14]. Snapshot retains its binary64
source values separately from the finite binary32 native numeric projection.
Normal axes still use visualMatrix, including identity for world-space PSGs.
No geometry or normals receive the authored transform a second time.
This is not retail spatial/cache parity and may differ visibly from PS2.
Authored UseLighting is retained, not reinterpreted as a native enable switch.
Existing raster material/fill/alpha/depth fields are untouched.

Remaining blockers / deliberately unfinished integration
This patch does NOT shade RGBA, install a generated static-diffuse renderer
stream, resolve model ambient/alpha defaults, or publish GPU readiness. Those
require an explicit recovered-source or documented native ambient/alpha policy.
The binding therefore remains a cold, fail-closed prerequisite: the aggregate
has no new camera-advance route, and no snapshot exists until a genuinely
published SourceCamera already exists. RA admission and trigger geometry remain
blocked. Coverage targets are untouched for the separate worker.
