The only algorithmic difference from the archived 529-based clipping patch is
final GPU transport of all four RGBA lanes. Internally, first-near clipping
still interpolates raw RGBA, then uses color*sourceW for the other five source
planes. At output it divides by sourceW, clamps and floors to final source
bytes. Those recovered bytes are then multiplied by nativeClipW and emitted
as smooth packetColorTimesClipW, matching the current stable fragment input.
Unclipped triangles likewise emit the untouched original RGBA*nativeClipW.
Fog transport is unchanged. No noperspective output remains in the RA stage.

The fragment shader is copied unchanged from d7472a2. Thus reconstruction,
texture sampling, byte modulation, alpha test, fog, destination composition
and source-depth output are untouched. Existing GPU input attestation and
resource lifecycle hooks are retained. The final RGBA transport is separate
from the source clipper's internal post-near C*W representation; they must not
be combined or applied twice.
