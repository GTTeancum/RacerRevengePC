## Authentic image selection

The canonical map token resolves the SAME retained texture root. For an ATM,
frameCount20/frame102050 enumerate its real children in original ordinal order.
Each child is decoded cold through the existing PST extent and byte-identity
checks. The bank keeps every frame, including the authenticated five-frame arrow
ATMs, before renderer binding. Static roots retain their one actual image.

Emission may only retrieve already cached Image objects. The fresh canonical
selected child must belong to that same ordered frame vector. FINAL identity,
GS fields, sampler values and native vertex-alpha ceiling must still match the
cold policy. A bank change or unsupported effective raster change rejects instead
of silently substituting an image or policy. Native bank IDs are private ordinal
identities; they are not asserted to be original texture IDs.

The renderer initializes samplers for every cold child and refreshes only the
selected bank ordinal from the successfully prepared native frame. It uploads
nothing during emission. Strong draw/resource ownership preserves the canonical
collector pin, Pause resources, child identities and decoded data until genuine
GPU retirement. Existing maximumMaterials bounds the entire cold image bank;
unsupported larger authored sets reject before GPU creation.

## Remaining limits

This increment does not implement arbitrary material callbacks, vertex animation,
non-unique controller cloning, shader parameter programs, or changing native GS
policies. It depends on actual bound Application clock publication and ordinary
Pause scheduler admission. Root alone owns compilation and runtime validation.
