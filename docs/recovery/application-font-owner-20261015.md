# Bounded Application font ownership for TimeStats

Source-only implementation. No build, syntax check or runtime test has run for this change. The passing Windows3d06b45 build predates it. No TimeStats HUD activation or GPU readiness is claimed.

## Implemented

The actual Application now has one lazy private Application328 font registry, declared after its retained canonical material domain/context. Its factory requires that same live Video-minted construction context and material application. Serial session close/reopen uses the existing stable Video/context identity; a closed host does not admit new loading. CPU entry leases never certify surviving GL resources.

The private load path admits only TimeStats193A0C's two authentic names, eurostileboldbold13ingame then denmarkbold16ingame, with reload0 reuse. Each new entry owns decoded original CEL metrics and exact archive provenance and retains one real canonical383400 texture row reference. It invokes the original full-table29E340 population boundary, preserves partial source effects and pending acquired state on failure, and resolves its actual resource before publishing. No fabricated material is used to obtain a texture reference. The only texture/domain access extension is a private friendship for this owner.

Application alone supplies actual mutable36B970 and the fixed36B420 font directory. Startup17C848/84C copies the authentic six-byte string at3A8600, `font\\` plus NUL. Per-font save/select/restore follows281EC0..281F44 after CEL decoding; the path is restored before successful manager publication and on native failures/exceptions.

Font objects retain the canonical domain, context and archive. Borrowed Entry handles are immutable strong native leases, without extra source texture references per borrow. A missing-font append refuses outstanding font leases. Explicit close refuses outstanding borrows without mutation; published entries release in insertion order. Violating destruction order terminates rather than silently discarding references, consistent with existing canonical ownership policy.

## Integration still required

- Actual TimeStats caller must mount/seal authenticated OVERLAYS and append its exact PST corpus into the same existing Application provider/resolver before loading.
- Load must occur before renderer publication or after genuine global retirement. Font leases cannot detect unrelated renderer borrows of the shared material/texture domain. No fake readiness flag was added.
- TimeStats ScreenText/draw owner, genuine bank/view/manager projection, resource-demand floor10, and renderer bridge remain separate work.
- The16ingame resource here is CEL/texture-only; its absent PSM warrants no fallback. Visible texts use existing13ingame.psm.
- Application/renderer shutdown must drop every Entry lease before destroying the registry. Do not close the process registry on each race exit.
- Full font-name registry, reload1, GPU residency and canonical frame-demand reset remain outside this bounded subset.

No call activates the new loader. The factory/loader are wired into the real Application interface for subsequent centrally owned HUD integration; they are not a diagnostic display.
