FAULT 1a  Teardown never releases the course archive (every run)
======================================================================
Evidence: cr15-01-TA line ~1395, cr15s-MC ~5470, cr15b-04-SA 1312, cr15b-10-SC 1279,
cr15b-15-RA (after a failed load) - all show
  common_teardown_holders role=collisions holders=1 preflight=1
  role=triggers 1, role=trigger_source 1, role=animation 3 (MC also water_resources 1)
  common_teardown role=archive released=0

Root cause: Track::release's preflight
(D:\Programming\GitHub\RacerRevengePC\.claude\worktrees\cr-main\tests\native\common_track_load50cr.cpp,
Track::release, the "Preflight" block) allows exactly 1 holder per role (2 for collisions
with the storage alias / particles with emitters). But every one of the "extra" holders is an
object INSIDE the same Track that the in-order release below drops by itself:
 - collisions +1: the navigation store's 1ACF70 world lease (NavigationStorage::worldLease,
   common_track50cr.h:358; Lease aliases the collision Owner, track_collision_world50cr.h:73-81).
   Release resets it first (navigation block), but the preflight runs before that.
 - triggers +1, trigger_source +1: the trigger action owner (roles.triggerActions, the same
   object the collision world keeps as actions_) holds group_ and source_
   (course_trigger_actions50ct.h:142-143, set in prepareSource :280). Dropped by its close()
   (:433), which the collision world's retire() runs (track_collision_world50cr.h:180).
 - animation +3: actions destinations_.animations (course_trigger_actions50ct.h:132/280),
   the collision world's animations_ (track_collision_world50cr.h:109/304) and its lane's
   runtime_ (track_animation_world50an.h:21/40). All three go at the collision world's retire().
   (Session's own copy is already gone: "session_holder_released=1 use_count_before=5" = Track
   + session + these 3.)
 - MC water_resources +1: the water runtime's resources_ (native_water_runtime50jc_fixture.h:222);
   water is released before water_resources.
So the preflight refused every teardown, on every course, including after a failed load (RA).

Change (common_track_load50cr.cpp, Track::release preflight): each internal holder is now
credited only when proven by identity, never by a count guess:
 - water: roles.water->resources().get()==roles.waterResources.get()
 - collisions: navigation worldLease shares the collision world's control block (owner_before)
 - triggers / trigger_source / animation: the action owner's nativeGroup()/sourceOwner()/
   animationOwner() equal the role (only while the action owner is open and held by at most
   the Track and the collision world, use_count<=2)
 - animation: collision world's animationLane() non-null (=> animations_ held) and
   lane->runtime()==role.
A real external holder still blocks exactly as before. Added
#include "native_water_runtime50jc_fixture.h" (header-only, already included by 5 TUs).
After a failed load the credits fall to 0 automatically for owners never built.
Log: new line `common_teardown_internal water_resources=.. collisions=.. triggers=..
trigger_source=.. animation=..` before the checks.
Fixed when: no `common_teardown_holders ... preflight=1` lines, then
`course_archive_release released=1` and no `consumed_close_rejected`.
Not proven: whether some role is ALSO held externally; the next log will name it (holders=N).
Note: the other release-order steps (collision close() with use_count==1, actions close, lane
reset) were not changed; if collisions still refuses at release time it will log
`common_teardown role=collisions released=0`.
