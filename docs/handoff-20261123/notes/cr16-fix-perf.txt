Water (src\game\original_water_surface50ws.h, tests\native\native_water_surface50ws.h; reached by 3 TUs:
terrain_interactive_continuation/loop/publication50du.cpp)
- WaterSurfaceWorkers50WS: 0-3 persistent host worker threads (hardware threads - 1, at most 3;
  RR_WATER_WORKERS=0..3 caps it, 0 = one-thread build). Made on the first water build, joined at process exit.
  The caller runs part 0. For every job the workers take the caller's MXCSR (rounding, flush/denormal modes)
  and fenv rounding, so every operation rounds as on the game thread.
- buildWaterSurface50WS(..., parallel=true) now runs three phases over a fixed contiguous partition:
  1 sample: grid-point rows [-1..rows]; the per-point ray/plane and sample() maths unchanged.
  2 normal: each emitted point's 4-neighbour normal, computed once and stored in the point. It was
    recomputed per pass and per strip sharing the point; same expression, same inputs.
  3 emit: strips in kick order. Strip s writes output slots [s*68, s*68+68) (pass A 34, pass B 34), the same
    order the old push_back produced. out is resized to the cold-reserved capacity (no new allocation).
  Every part writes only its own slots and its own counter row; every slot access goes through a bounds-checked
  accessor (refused, not written, if out of range). Counters are merged in part order: sums, plus min/max.
  The min/max equal the old running min/max over the same points. The degenerate-normal count still counts
  per emitted vertex.
- Requirement noted in the code: f.sample must be re-entrant and read-only. The one sampler
  (native_water_surface50ws.h sample()) only reads the completed water runtime and uses a local Math.
- Logs: native_water_surface (every 625 frames) gains "build_ms_avg/worst=x/y build_frames=N parts=P",
  averaged over the builds since the previous line. render_cost_ms water_build_avg also still shows it.
  RR_WATER_VERIFY=1 (muted A/B run only): every 625th build is repeated on the calling thread alone and
  compared byte for byte (vertices and counters): "native_water_verify ... result=match|differs".
