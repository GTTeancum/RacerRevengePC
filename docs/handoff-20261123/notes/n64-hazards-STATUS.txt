4. WHAT THE CONVERTER MUST PROVIDE (exact keys, as the port reads them)
-----------------------------------------------------------------------
Common to every N64 row - TOB [Triggers] NumberOfTriggers counts them; one TriggerN block each:
  N64Volume        Plane | Capsule                        (required; marks the row as N64)
  Position         x,y,z centre, Revenge space            (required)
  N64Direction     dx,0,dz horizontal, length 0.5..2      (required; normalised by the port)
  N64HalfWidth     size_xy/2 ft, 0 < v <= 5000            (required)
  N64HalfHeight    size_z/2 ft, 0 < v <= 5000             (required)
  OneTimeOnly      T | F                                  (required)
  NumberOfActions  1                                      (required; exactly one N64 action)
  SurfaceObject    comma list of carrier static instance names (27A524 rule: to the first dot,
                   <= 50 chars), max 16; absent = any surface
  MinSpeed 150 / LocalOnly T / Laps 1,2,3   only when the N64 flags are set
  Zone            1-based SCB zone holding the centre (required, 1..zone count; checked by the
                   common reader). StartEnabled T (default T), Name (log only).
  Max 32 N64 rows per track. A Revenge ActionType on an N64 row is refused.
Floor under the line in flight: tracks\<code>.nft (already written by tools\n2r\n2r_floor.py for
  ZeroGravity tracks; no change).

Energy column (104) - TriggerNAction1:
  ActionType ExplodePod; Side Random|Left|Right (default Random); Gate LocalOrNearCamera|Local|All
  (default LocalOrNearCamera); NearCameraDistance (default 1000, 0..100000); AfterDestroy
  Respawn|Retire (default Respawn); RespawnDelay s (default 3, 0..30; N64 value still open).
  Row: Plane, OneTimeOnly F, SurfaceObject = the column instance.

Breakable asteroids (102) - TriggerNAction1:
  ActionType BreakObject; AnimationNumber N (1-based [Animations] row) or AnimationNameRef
  (<= 39 chars, ReferenceName, last match wins); ThrustDeceleration 2.5; DamageTotal 0.15 (0..1);
  DamageBoostScale 4 (0..16); DamageHits 3 (1..8); EffectAnimationNumber or EffectNameRef = the
  debris row; EffectAhead 12; EffectAiScale 8 (0..64); EffectFade 2 (0..30); FileName (sound,
  <= 259 chars), Pitch 0.25, PitchRandom 0.15, MinDistance 10, MaxDistance 500. Defaults are these
  N64 values. Row: Plane, OneTimeOnly T, SurfaceObject = that trigger's carrier meshes.
  Each asteroid: its own [Animations] row (KeyFramed, one-frame pose, SequenceActive1 F,
  LoopSequence1 F, UseCollision T) and NOT in the static world. Debris row: SequenceActive1 F, LoopSequence1 F,
  UseCollision F, StartHidden T.

Door (101) - TriggerNAction1:
  ActionType AnimationToggle; AnimationNumber or AnimationNameRef = the door row; ToggleGuard 3.0
  (0..600); ToggleRate 20 (0..1000); FirstTrigger Freeze (only value). Row: Capsule, OneTimeOnly F.
  Door row: 13.33-s closed->open motion, SequenceActive1 T, LoopSequence1 T, UseCollision T.

Fan - no trigger: [Animations] row, 24-s motion keyed densely enough to match the N64 slerp,
  SequenceActive1 T, LoopSequence1 T, UseCollision T; not in the static world.

Falling pillar (312) - TriggerNAction1:
  ActionType AnimationPlay; AnimationNumber or AnimationNameRef = the pillar row; Rate 0.6 (signed,
  -1000..1000, not 0; default 1); Show F (default); camera shake through Revenge's own fields:
  ShakeMagnitude (0..1000), ShakeTime s (0..60), ShakeDecaying 0|1 (default 1), ShakeDelay s
  (0..60) - any of them present = shake issued. N64 'Shak' 4.0 is not decoded into these
  fields: the converter chooses (suggest ShakeTime from the N64 value only once decoded).
  Row: Capsule (the N64 record), OneTimeOnly T, LocalOnly T, SurfaceObject = carrier.
  Pillar [Animations] row: its N64 fall motion keyed at N64 animation time (speed 1; Rate 0.6
  makes the 2.6-s fall), SequenceActive1 F,
  LoopSequence1 F, UseCollision T; not in the static world.

Methane bursts (314) - TriggerNAction1:
  ActionType AnimationPlay; AnimationNumber or AnimationNameRef = the FX row; Show T; Rate 1
  (default). Row: Capsule, OneTimeOnly T, LocalOnly T, SurfaceObject = carrier.
  FX [Animations] row: model 293 and its animation, placed at the marker node (Offset),
  StartHidden T, SequenceActive1 F, LoopSequence1 F, UseCollision F.

Revenge CameraShake (any course, original action) - TriggerNActionM:
  ActionType CameraShake; Magnitude, ShakeTime, Decaying, Delay (all optional; 0, 0, 1, 0).
  Usable on ordinary Revenge trigger rows (Radius/Box), not on N64Volume rows.

Every animated object: report total vertices / indices / spans against the window budget
(8192 / 32768 / 64) per track.
