1. WHAT THE ORIGINAL DOES (SLUS_202.68, class DrawableCube, source file "Cubedraw.cpp")

Load
- 1295B0 loads ALL internal cubes of the CUB into a cube table (owner+3C, count +7D8);
  current cube +38 = cubes[0] (the base cube). It then calls 1299A0.
- 1299A0 builds the companion name: copy the cube path, strrchr '.', replace the extension
  with ".acb" (append if no dot) -> "skies\gb.acb". Opens it as a text config (157320/1577D0).
  If the file is missing, it returns: no sequences, base cube only. Of all stock archives
  only GB.RES holds an .acb (scan of every TRACKS\*.RES), so every other stock course takes
  this no-op route.
- [Sequences] NumSequences (default 0; <= 0 = nothing). Per [Sequence%d], a 40-byte row:
    +00 StartFrame-1, +04 EndFrame-1, +08 int(end-start), +0C FramesPerSecond,
    +10 IdleTime, +14 RandomStartChance (default 100), +18 elapsed = BeginTime (default 0),
    +1C once-per-second check = 1.0, +20 frame = 0, +24 bit0 active = 0.
  All other defaults 0.
- [CubeMapping] Face1..Face6Mapping: comma list of panel ids per tile (0 = none), stored in a
  6 x 16 table of panel records at owner+50 (id, count, up to 3 sequence numbers).
- For every nonzero panel: [Panel%d] SequenceList = 1-based sequence numbers. Asserts: at most
  3 per panel ("SequenceList too high"), number <= NumSequences, and every cube from
  StartFrame-1 to EndFrame-2 must carry that face/tile ("Missing panel").

Timing (12BB50, the SkyCube update; called from 288B00 = SkyCube vtable slot 38 with the
object-system frame time; only the camera-zone-selected sky cube is updated, 275860..275964)
- Every inactive sequence: elapsed += dt (even while another sequence is playing).
- If none is playing: walk the sequences in order; a sequence is eligible once
  elapsed > IdleTime; its once-per-second check: if check < 1, check += dt and skip, else
  check = 0 and roll ONE shared percentile 0..100 (lazy 80A8/3D6B30 seed from 101A50, 308030
  draw, "assumption violated in GetRandomNumber" Defs.h - the same shared random stream and
  steps the port already uses in track animations and the Garage). If percentile <
  RandomStartChance the sequence starts (active, current = it) and the walk stops. Only one
  sequence plays at a time.
- While one plays: frame += dt * FramesPerSecond; once frame > (EndFrame-StartFrame) it ends:
  frame = 0, elapsed = 0, inactive.

Draw (12C540 GetTextureMap, called per tile from the cube draw at 12C290)
- Tile gating, geometry and blend are unchanged: the base cube's visible and authored masks
  gate each tile (12C26C..12C284), opaque, same quads.
- A tile whose panel lists the playing sequence takes the texture of cube
  int(frame + StartFrame-1) for that face/tile (asserted < cube count); if that cube lacks the
  tile it falls back to the base texture. Every other tile keeps the base texture.
  So a flash is a short flip-book of whole sky tiles: no fade, no blend, no colour change.

GB's data (skies\gb.acb, 1,334 bytes, copy at
D:\Programming\GitHub\RacerRevengePC\work\scratch\racer-arcade\export\a2r\orig\GB\skies__gb.acb)
- 5 sequences, 30 frames per second, idle 2-3 s, begin head-starts 0-5 s, start chance
  40-50% per one-second check. Each flash steps through 4-6 overlay cubes, lasting roughly
  a sixth to a fifth of a second.
- 8 panels: face 1 tiles 4-7 (panels 1,4,5,6), face 2 tiles 5-6 (panels 2,3),
  face 4 tiles 4-5 (panels 7,8). These match exactly the tiles present in cubes 1-6 of
  gb.cub (masks 240/96/0/48), and every "Missing panel" check passes.

Separate, already ported: the scene's own ambient-light flash ([Environment]
