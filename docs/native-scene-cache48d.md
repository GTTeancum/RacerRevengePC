# Native scene cache 48D

The Windows converter now uses `decodeScene48D` and writes `RRSCENE1` semantic scene objects alongside the previous `RRMESH01` inspection export. The converter identity is `rr-native-scene-48D-v1`; existing 48C cache objects remain recoverable, but cannot be reused under the new identity. The containing cache, generation and current-pointer schemas remain compatible because their object records already carry a converter version.

Each object preserves original node names, parent links, local and composed bind matrices, original node bounds, material names, world/local flag, quantization metadata, all original LOD cutoffs, per-surface material selection and UV metadata, local positions, local normals, UVs, rigid bone selection, color-presence flag, original color bytes and triangle indices. Recovery-only source offsets and packed-strip diagnostics remain in decoder evidence rather than the runtime file. Missing vertex color is still explicitly absent; white exists only in the neutral inspection mesh.

All fields are encoded individually in little-endian order. The file starts with eight bytes `RRSCENE1`, a u32 version 1, world-space and identity-palette u32 booleans, node/material/LOD/total-vertex/total-surface u32 counts, and seven binary64 quantization values. Nodes carry length-prefixed byte names, a u32 parent (0xffffffff means root), then 16 local, 16 bind and seven bounds binary64 values. Materials are length-prefixed names. Each LOD contains a binary64 cutoff and surface count. Each surface contains a material index, color-present boolean, binary64 UV-size metadata, vertex/index counts, then vertices and indices. A vertex is eight binary64 values (XYZ, normal XYZ, UV), four color bytes and a u16 bone ID. Indices are u32. LOD0 spans are six u32 fields each: material, vertex start/count, index start/count and color flag. Finally, a u32 byte count precedes the compatible RRMESH01 inspection export. No host structure, pointer or PS2 command stream is serialized.

The bounded loader validates finite numbers, counts, parent order, affine matrices, exact local-to-parent bind composition, all-LOD original node bounds within the established quantization allowance, bone/index ranges and contiguous material spans. It verifies the inspection export against the scene's bind positions, UVs, color convention and indices. Rejected parses and encodes leave previous outputs untouched. The cache record hashes both files and validates their agreement before a generation can become active. Both files are staged and verified before metadata promotion; cancellation or failure still leaves the previous current pointer intact.

`racer_native_pc --scene object.rrscene` loads semantic attributes, builds native draw buffers from local positions and bind transforms, and draws the original LOD0 surface spans separately. It retains the scene data for later pose/material work. This diagnostic view uses the existing neutral or single-texture inspection shader: normals, material shaders, runtime pose, LOD selection, visibility and scene instances are not yet implemented in rendering. The reported asset-byte payload covers packed draw buffers and the optional single texture, not all scene allocations. No race performance claim follows from these inspections.

The native cache regression exercises all 228 supported TA scenes and 13 Pod01 scenes, compares every preserved semantic field, checks canonical round trips, corrupt/truncated inputs, transactional failure, contradictory hierarchy/bounds and the neutral export. The independent decoder regression separately checks those 241 outputs and semantic fields against frozen Python48C evidence derived from the original files.
