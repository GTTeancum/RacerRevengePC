## Usable common join

`original_player_identity50ik_fixture.h` centralizes all eight exact original
IDs, archive sizes/SHA-256, PHY hashes, three speech-category hashes, and named
Dax size/count/hash. It supplies the shared cold archive and announcer paths.
These are copied from the retained source files, not generated authoring.
The constructor proof remains the50IJ proof: original vehicle60 is the same
argument formatted as `Pod%02d`; host slot numbers never supply character IDs.

The selected gameplay loader now reads every pod-owned category, counts and
PHY from the selected authenticated RES, including POD01. Only the unchanged
TA intro and source literal boost use the existing shared reader. That reader
still needs POD01 data, already required by this eight-original field. No
alternate racer borrows Anakin's speech, engine tuning, wreck or event table.

Semantic bank/key slots remain unchanged. POD01 uses60 authored slots; the
other seven use48. Unauthored keys remain empty and reject commands. PCM
requests are deduplicated only when identical original names and flags alias;
selection keys/cursors/history are not merged. No hot capacity, voice range,
cooldown, group policy or shared-RNG arithmetic changes.

Both lap owners, both Dax modes and the opponent engine mapper consume this
one identity table. Dax preserves each file's own29/30 event count; the
existing source owner still selects the54 represented semantic keys and
deduplicates their immutable PCM as in50IJ. Other original Dax event types
are not invented by importing their metadata.
