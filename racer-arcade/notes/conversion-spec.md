# Conversion spec: Racer Arcade data -> Racer Revenge PC files

2026-11-12. Read-only research; nothing in the repo was changed. Builds on
`D:\Programming\GitHub\RacerRevengePC\work\scratch\racer-arcade\notes\revenge-target.md` (Revenge side)
and the Arcade notes `program-map.md`, `mask-map.md`, `hikaru-hardware.md`, `asset-tables-*.txt`,
`mesh-check\README.md` in the same folder. `courses.md`, `pods.md`, `race-data.md` did not exist yet
when this was written; rows that depend on them are marked **(pending export)**.

Governing rule (`D:\Programming\GitHub\RacerRevengePC\CLAUDE.md`): new courses and pods are **data
only**. The converter writes ordinary Revenge files (RES3 archives and loose files) that the one
common race-load path reads exactly as it reads the originals. No Arcade-specific code in the game.

Legend for "source": **A** = taken from Arcade data (address given), **G** = generated by the
converter (no Arcade source), **D** = copied from a donor Revenge file and edited (flagged as a
stand-in in the converter output), **(guess)** = not yet proved.

### 0.2 Texture target

| Arcade source | Revenge target | Notes |
|---|---|---|
| ABGR1555 (1,556 textures), ABGR4444 (587), 16..512 px, power-of-two, full mip chain, level 0 first (`mask-map.md`) | **PST revision 1, kind 1** (8-bit indices, 256-entry RGBA palette, 4 bytes per entry, alpha 0..255) + a PSM material | Converter quantises to 256 colours per texture. Revenge's own palettes mostly use alpha 255 for opaque (TA: 32 of 35). |
| | kind 0 (4-bit, 16 colours) for small or flat textures | optional, to save size |
| | kind 2 (16-bit 1555, direct) | lossless for ABGR1555 sources, but in the port it is only proved on some paths (IPUM/Garage, `src\assets\original_standard_texture_resource50la.cpp:1434,1551,3038`). Do not use for world/pod textures until the common texture path takes kind 2. |
| Mips | PST stores levels **smallest first**, each mip header {u32 height, u32 width, 0, 0}; 1-7 levels; sides 16..1024 and power-of-two (the port rejects smaller levels or odd sizes, `src\assets\import_texture48e.cpp:116-170`) | regenerate the mip chain from Arcade level 0 (box filter); drop levels below 16 px. |
| Format detail | Arcade texel word: R 4:0, G 9:5, B 14:10, A 15 (1555), or R 3:0 .. A 15:12 (4444); in ROM the two texels of each 32-bit word are swapped (`hikaru-hardware.md` 3.7) | unswap pairs, expand to 8-bit per channel (x255/31, x17), then quantise. |
| 2D images (menus, HUD, course-select) | UI PST / IPUM in the UI RES files | only for menu assets (holograms, rider portraits). Optional. |

Material (PSM) for every texture: ASCII INI `[General] TotalShaderPasses = 1`, `[ShaderPass_1]
microProgramName = PreLitCompressed`, `TextureMap_1 = <name>` (TA sand, `textures\ta_sand8.psm`).
Add the pass flags Revenge uses for alpha-tested or alpha-blended surfaces (decide per texture from
its alpha: 1555 with any A=0 -> alpha test; 4444 with partial alpha -> blend). The microprogram for
lit (non-prelit) pod surfaces is copied from a donor pod PSM (**D**).

### 0.3 Geometry target (PSG v3)

Every Arcade display list becomes one PSG v3 file (`docs\asset-decoder48b.md`):
hierarchy count; per node a 128-byte name, 64-byte matrix, bounds centre/half-size/radius, parent;
material names (-> PSM); LOD and surface records; packed VIF strips with signed-16 positions
(quantised around the node's centre with a per-object scale), signed-8 normals, signed-16 UVs,
unsigned-8 vertex colours; strip restarts use the observed ADC encoding (-16 runs, not the later
0x8010 form; the decoder rejects the later form).

| Field | Source | Conversion |
|---|---|---|
| Positions | **A** static vertex `(int32(w)>>10) * 2^(p-0x8D) / 64` (`hikaru-hardware.md` 3.5) | x scale (0.1), translate (0.1), then quantise per object. Split any model whose extent / 65,536 makes the quantum coarser than about 0.2 ft (Revenge ground pieces use ~0.21 ft). |
| Triangles | **A** 3-vertex window, triangle closed on the 158 texcoord push, pivot bit, winding bit | Fix the strip/fan assembly first (`mesh-check\README.md`: pod hull has holes). Emit Revenge strips; keep source winding. |
| Normals | **A** 10-bit signed /256 | renormalise, pack to signed-8. |
| UVs | **A** signed 16-bit in 1/16 texel (or whole texels if 2C1 bit 14) | divide by texture size -> normalised; pack signed-16 with the PSG UV scale. |
| Vertex colours | **G** - Arcade lights at run time (Gouraud, up to 4 lights, material diffuse/ambient/specular in the list) | Bake: colour = ambient + sum(light x max(0, N.L)) x material diffuse. Store in Revenge's prelit range: TA ground uses about 63-128 per channel, where 128 is unlit full brightness (PS2 2x convention). Do not double these values or force alpha opaque (`docs\asset-decoder48b.md`). Flag the result as generated lighting. |
| Materials | **A** texhead index per list, relative to the course texset or the pod texgroup | resolve to texture id, then PSM name. |
| Node names | **G** | course: `<code>_<object>_<n>`; pods: Revenge names that the code looks up (see section 3). |

### 0.4 Collision target (COL v1, type 0)

`col\0`, magic 1234, version 1, type 0; 12 floats basis + translation (identity); reverse 0; vertex,
node and face counts; quantised flag 0; float vertices; optional vertex normals; AABB tree nodes
(volume, centre, half-size, two u16 children, bit 15 = leaf); faces (D, normal, 3 u16 indices)
(`docs\native-collision48g.md`).

| Field | Source | Conversion |
|---|---|---|
| Triangles | **A** 196-byte records: centroid, radius, v0/v1/v2, vertex normals, plane data, ids (`mask-map.md`) | scale/translate; plane D recomputed after the transform. |
| Tree | **G** | build a balanced AABB tree; the original format has no material per face. |
| Split | **G** | one COL per zone model: Revenge tracks carry 36-320 COL files, each paired with the placed models of a zone. u16 indices mean at most 65,535 vertices per file. |
| Surface type | **A** if the per-triangle "ids" turn out to be surface ids (**pending export**), else **G** by texture | Revenge surface is not in COL; it comes from the material-audio file (`.aub`, collision-object material N -> object list) and the collision tags (`src\assets\track_collision_tags50an.cpp`). |

### 0.5 Text and binary parameter files

* INI files (`.spl`, `.tun`, `.pos`, `.wtt`, `.phy`, `.ai`, `.cam`, `.ini`, `.prt`, `.emt`, `.mcf`,
  `.vut`, `.psm`) are written as CRLF ASCII, one key per line, matching the original spelling and
  section order. The port's readers are strict (bounded ASCII, no duplicates,
  `src\assets\ai_authoring50iu.h`).
* `BINARY\0` parameter-block files (`.scb`, `.tob`, `.aub`) are the compiled form of text files
  (`.scn`, `.toy`, audio). GC ships both `gc.scn` and `gc.toy` next to the binaries, so the
  converter writes the text, then compiles it with a BINARY writer that matches the port's
  reversible reader (BINARY1, used for TA.aub, `docs` world-scene48e / native-world-converter48f).
  Round-trip check: decode -> re-encode the 13 originals byte-identical before writing new files.
* RES3 archive: header (3, meta, 0x340, 0, table bytes), u16 compressed-size table ending in zero,
  member index {u32 name length, name, u32 logical offset, u32 bytes}, then 24,576-byte blocks, each
  zlib-compressed and followed by 0xFF (`src\assets\import_decode48c.cpp:147-286`). Member names use
  backslashes and the original folder names (`geometry\`, `textures\`, `tracks\`, `skies\`,
  `particle\`, `audio\`, `anim\`, `Pods\Podnn\`).

## 2. Course slots

### 2.1 Codes

The physics class (`src\game\authored_parameters49n.cpp:106-118`, original 214954): lower-case 'a'
anywhere -> class A, else 'b' -> class B, else class C; then the exact codes `sb` -> C,
`ra` and `sc` -> B. Class picks the PHY `...A/B/C` values (MaxThrust, TheoreticalTopSpeed,
SpoilerYawMoment, Defense, BaseRepairAmount, BaseCoolingTime). It is separate from the AI class,
which comes from tournament order (section 2.3).

| Course | Code | Physics class | Why |
|---|---|---|---|
| Etti IV "Smuggler's Cove" (Arcade: normal) | **`eb`** | B (has 'b', no 'a') | first letter E is unused; difficulty matches the Arcade grading |
| Malastare "Pixelito Challenge" (Arcade: hard) | **`lc`** | C (no 'a' or 'b') | M is taken by Mon Calamari and `ma` is a course; L from maLastare |

Codes already in use: ta tb tc ra rc ma mb mc ga gb gc sa sc, plus the END cutscene banks. File names
follow: `TRACKS\EB.RES`, `tracks\eb.scb/.tob/.aub/.tun`, `tracks\aeb.spl`, `tracks\meb.spl`,
`tracks\eb01.vub..`, `tracks\ebTVCam.pos`; same for `lc`. Any code with an 'a' gives class A (for
example `ea`), so the class must be chosen deliberately with the code. For the later Tatooine
courses: no Tatooine-letter code with 'a' is free (`ta` is used), so an easy-class code would need
another first letter (for example `ua`, class A), and Boonta Classic could be `td` (class C).

Placement decision for the tournament: AI class follows the order index. Appending the two new
courses after order 12 makes both AI class C and puts them in the Hutt Championships. Placing
Etti IV inside orders 5-8 instead would shift existing courses and change their AI class, which
changes original behaviour. Recommendation: add them as a fourth circuit (orders 13-14, AI class
taken by the same rule, so C), or leave them out of the tournament and race them as single events
