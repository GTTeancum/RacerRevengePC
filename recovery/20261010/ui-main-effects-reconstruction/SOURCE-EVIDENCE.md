# Original Main audio: concrete native transport

New source reconstruction, 2026-10-10. Original executable/data were read statically. No project parser/importer, decoder, compiler, syntax check, test, game or emulator was executed. The two staged C++ files are unbuilt and unvalidated candidates.

## Deliverable and application contract

`files/platform/linux/native/original_ui_main_audio50kg.{h,cpp}` provides `rr::platform::OriginalUiMainAudio50KG`.

`prepare(audioRoot, dedicatedFrontendMixer, error)` cold-authenticates `UIEVENTS.INI`, `UI_MUSIC.JUK`, `UI_MUSIC.JUB`, the actual Main Song9 VAG, and four exact event VAGs. `audioRoot` is AUDIO itself. No directory guessing, symlinks, substitute sounds, IOP execution or test-fixture dependency is admitted. It owns original-derived PCM and lends stable sample pointers to the caller-owned mixer.

The application must supply a freshly initialized, dedicated frontend mixer and voice array, at a stable lifetime exceeding this owner. Five voices are required: slot0 music, slots1..4 select/left/right/badcall. These are native storage slots, not original SPU addresses. This is separate from race slot117 and all race/material voices. The application must reset Main transport and close its output before enabling race output; concurrent frontend/race output is not admitted. Reinitializing the mixer invalidates this owner through the existing mixer epoch. The owner never reinitializes another mixer or stops unowned voices.

Session calls are `ready`, `startMainLoop9`, `fadeMain`, `playMenuEffect`, `update`, `pause`, and `reset`. `mixStereo16` is the application's gate to this dedicated mixer: during pause it writes silence without consuming source PCM. No device callback invokes this owner. Source update receives finite seconds in [0,1], once per accepted source tick. All runtime operations are allocation-free and have no filesystem reads.

Muted native-session mode is an application decision with an explicit suppressed receipt; a null audio owner in that mode does not claim playback. A source no-active fade returns false, as the original helper also returns0. Original Main ignores the fade helper's return; the session must not turn this no-active/source-suppressed case into a visual transition error.
