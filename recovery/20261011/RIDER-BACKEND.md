## Source corrections and phase ownership

argument is an entity mask stored in child+20 and aggregated into ancestor+24.
Values2/100A/8 are NOT numeric scheduling priorities. Real hierarchy is widget ->
model -> binder0,binder1 -> each primitive. See evidence/entity-append.txt.
The dynamic-owner header terminology is corrected accordingly.

Parent+A4 at2A4B30 calls14D370/29E340/14D440. The first two genuinely populate
referenced material/texture resources; the last rebuilds source material groups.
The backend concretely supplies the authenticated native CPU resource/image
population. COMPLETE native pass scheduling and GPU bank publication are still
required in the composer before a usable destination exists. Do not describe
attachment alone as native rendering readiness.

The backend deliberately owns no borrowed model-packet queue. A complete composer
must copy projection output into its own vertex/W/fog arrays synchronously under
beginFrame/endFrame; selection cannot run inside that lease. Before destruction,
drain the composer and retire its renderer source owner, then drain the dynamic
owner while backend remains alive. Previously sealed draws must be invalidated
when backend generation changes. GPU bank identity must match the exact current
CPU bank. No identity is merged by owner-local numeric image ID.
