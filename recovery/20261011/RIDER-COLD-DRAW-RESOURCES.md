## Interface/lifetime contract

load is atomic and retryable on failure. A loaded owner cannot be replaced.
The caller supplies the real640x448/32-bit original native video lifetime,
packet Z maximum0xffffff, ZBUF0x31 and known material runtime overrides.
No GL state or destination readiness is published.

bankInput() owns archive pins and a single owner0 image bank. The live Rider
backend appends stat/binder/model owners. It must preserve this owner ordinal
and remap each material's image index through its actual combined-bank mapping.
The static images and source policies cannot be sent to a different GPU bank
by treating their equal numeric IDs as equivalent images.

widgets() is the real callback state owner. Selection/session work remains in
its concrete dynamic backend and page owner. Animated Icon89/90 cold layouts
use the first constructor image dimensions; composer must still select the
actual current material frame, and must not reject the icon because the bound
geometry references constructor frame0. Every source unique animation has its
own live animation owner and clock, outside this cold resource object.

Borrowed materialName strings in background/prompt quads remain stable because
all material population completes before those pointers are installed, and the
owner never appends or replaces bindings after successful load. Pins must
outlive all borrowed projections and complete frame draining.
